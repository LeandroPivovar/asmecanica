# AS Mecânica

Site institucional estático (HTML/CSS/JS, sem build). Os arquivos publicados ficam em `dist/`.

## Vercel

Importar a raiz do repositório com framework **Other**. O `vercel.json` define a saída `dist`, sem build nem instalação.

## Direção visual (Taste)

*Chapters in flat colour*: cada seção é um capítulo de cor chapada de parede a parede (vermelho, preto, cinza e
branco do logo), unidos por Barlow Condensed e uma grade só. A frase do perfil é o capítulo vermelho. Item interativo:
montador de orçamento (problema, se o carro roda, modelo). Hero no padrão obrigatório Aroe.
